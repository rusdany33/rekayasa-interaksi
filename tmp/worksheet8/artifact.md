# Acuan Worksheet 8

Acuan isi adalah workbook lokal pada Pertemuan 08 From Insight to Requirement, blok 450 sampai 498. Workbook merupakan panduan isi, bukan template tampilan laporan yang diminta disalin. Format laporan mengikuti preferensi pengguna sebelumnya: hitam putih, Times New Roman, laporan akademik rapi.

Slot wajib pada template mahasiswa: Nama, Tanggal Analisis, Berkas Bukti Pendukung; Bagian A dengan empat kolom Research Insight, User Need, Functional Requirement, UX Requirement; Bagian B minimal lima User Stories dengan As a [user], I want to [action], so that [benefit]. Enam baris pemetaan serta enam cerita disusun. Data riset dikaitkan dengan WS3, WS5, WS6, WS7. Rubrik Classroom menambahkan prioritas dan alasan.

Panduan asli dipertahankan tanpa perubahan. Judul disanitasi sebelum render dan import Google Docs. Font hitam dan tanpa border judul merupakan preferensi pengguna serta persyaratan sanitizer.
